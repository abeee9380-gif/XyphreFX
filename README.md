# 🌦️ XyphreFX

> Bring your desktop to life with beautiful, dynamic weather effects.

XyphreFX is an open-source desktop application that adds immersive weather animations and visual effects to your Windows desktop. Whether it's rain, snow, fog, or sunny skies, XyphreFX aims to make your desktop feel alive.

## ✨ Features

* 🌧️ Real-time weather-inspired effects
* ❄️ Rain, snow, fog, and more
* ⚡ Smooth animations
* 🎨 Lightweight and customizable
* 🖥️ Designed for Windows
* 🚀 Open source

## 📥 Installation

1. Download the latest release.
2. Run `Setup.exe`.
3. Follow the installation steps.
4. Launch XyphreFX and enjoy!


> **Note:** Because XyphreFX is a new application and is not digitally signed yet, Windows SmartScreen or Microsoft Defender may display a warning. This is common for newly released software. And this app has two options to be displayed in. 1) is the windowed mode 2) is the desktop mode .You can change in what mode you wanna set when you start up your computer.
